# 记账系统（ZBCX Account）

基于 `flutter-zcj/prjtmpl`（uni-app + Vue3 前端）与 `flutter-zcj/RuoYi-FastAPI`（FastAPI 后端）搭建的个人记账系统，部署于华为云主机 `<SERVER_HOST>`。

## 一、访问方式

| 项目 | 地址 |
| --- | --- |
| 前端页面 | https://<SERVER_HOST>:8081/account/ |
| 后端接口根 | https://<SERVER_HOST>:8081/account-api/ |
| 后端直连（内网） | http://127.0.0.1:9100/ |
| 接口文档 | http://127.0.0.1:9100/docs （仅服务器本机） |

默认账号：`admin` / `admin123`（验证码已关闭，便于移动端登录）

## 三、服务管理

```bash
systemctl status  zbcx-api      # 查看状态
systemctl restart zbcx-api      # 重启后端
systemctl stop    zbcx-api      # 停止后端
journalctl -u zbcx-api -f       # 实时日志
```

后端已设置 `Restart=always` 且开机自启。

## 四、数据库

| 项目 | 值 |
| --- | --- |
| 实例 | PostgreSQL 18.6 @ 127.0.0.1:5432 |
| 数据库 | `zbcx_account` |
| 用户 / 密码 | `zbcx` / `<DB_PASSWORD>` |
| Redis | 127.0.0.1:6379，database `3` |

业务表：

- `t_acct_category`：记账分类（首次访问自动初始化 16 个默认分类：支出 10 + 收入 6；`icon` 存 emoji）
- `t_acct_bill`：记账账单（逻辑删除 `del_flag`；`bill_type` 0支出/1收入/2转账；含 `account_id`、`to_account_id`、`tag`、`images`）
- `t_acct_account`：资产账户（现金/储蓄卡/信用卡/花呗/理财/借入/借出/微信/支付宝/其他，余额**不落库**，由账目实时聚合）
- `t_acct_budget`：预算（`budget_month` + 可空 `category_id`，为空表示当月总预算）
- `t_acct_recurring`：周期规则（`rule_type` 0每天/1每周/2每月/3每年 + `next_run_date`）
- `t_acct_ledger`：账本（`invite_code` 唯一，`is_default` 标记默认账本）
- `t_acct_ledger_member`：账本成员（`role` 0拥有者/1成员）

RuoYi 平台表共 53 张，由 `sql/ruoyi-fastapi-pg.sql` 初始化。

## 五、功能说明（v2.0 参照鲨鱼记账还原）

| 能力 | 说明 |
| --- | --- |
| 三种账目类型 | 支出 / 收入 / 转账。转账只搬余额、**不进收支统计** |
| 自定义键盘 | 4×4 键盘，支持 `+ − × ÷` 与 `=`，用调度场算法求值，不依赖 eval |
| 分类九宫格 | emoji 图标 + 分类配色，可跳转管理页增删改 |
| 账户与余额 | 余额 = 期初 + 收入 − 支出 ± 转账，实时聚合；借入类单独计入负债 |
| 标签 | 每笔账单可挂标签（≤4 字），全局搜索可命中 |
| 图片凭证 | 选图上传至 `/www/wwwroot/account/uploads`，最多 3 张 |
| 明细 | 按日分组，每日小计支出/收入；点击编辑，长按删除 |
| 统计 | 环形占比 + 分类条形 + 近半年趋势 + 单笔排行 |
| 预算 | 总预算 + 分类预算，进度条按当月实际支出计算 |
| 搜索 | 分类名 / 标签 / 备注 / 金额四字段联合模糊匹配 |
| **AI 对话记账** | 说「午饭 35 微信」自动解析金额/分类/账户/日期，规则引擎打底，可接 LLM |
| **图片识别记账** | 上传支付截图/小票，服务端 OCR 提取金额与商户，预填表单 |
| **周期记账** | 每天/周/月/年，到期懒执行补记，幂等可重复触发 |
| **共享账本** | 多账本隔离，邀请码加入，成员共用同一份收支（账户/分类仍个人级） |

**未实现**：语音记账（需 ASR）、Android 截屏监听（需 MediaProjection，H5 无法调用）。

## UI 与图片（v3 视觉重构）

- **图片全部来自 Unsplash**：分类图标按分类名匹配照片（餐饮→美食、交通→汽车…），共 28 张，已按展示尺寸裁剪后内置在 `src/static/account/`，首屏不依赖外网；`src/utils/account/photos.js` 统一分发。
- **线性图标系统**：`src/components/acc-icon/acc-icon.vue` + `src/utils/account/icon-paths.js`，SVG 走 CSS mask 着色，任意尺寸换色不糊；底部导航、工具栏、单元项均已替换。
- **界面按参考产品重排**：底部「明细 / 统计 / ➕记账 / 资产 / 我的」五段式带凸起记账按钮；首页绿色渐变概览 + 按日分组白卡明细；记账页「支出/收入/转账」胶囊切换 + 照片九宫格 + 计算键盘；资产页深色净资产卡。
- **代码规范**：全部页面按 `style → template → script` 排列，样式单行写法、选择器间无空行、style 内零注释，script 带组件头 JSDoc 与逐方法注释。

## 六、接口清单

所有接口需 `Authorization: Bearer <token>`，token 由 `POST /login` 获取。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/login` | 登录（表单 `username`/`password`） |
| GET | `/account/category/list` | 分类列表（`categoryType` 可选 0支出/1收入） |
| POST | `/account/category` | 新增分类 |
| PUT | `/account/category` | 修改分类 |
| DELETE | `/account/category/{ids}` | 删除分类（逗号分隔） |
| GET | `/account/bill/list` | 账单分页（`pageNum`/`pageSize`/`beginDate`/`endDate`/`billType`/`categoryId`/`keyword`） |
| POST | `/account/bill` | 新增账单 |
| PUT | `/account/bill` | 修改账单 |
| DELETE | `/account/bill/{ids}` | 删除账单 |
| GET | `/account/stat/summary` | 收支汇总（`beginDate`/`endDate`） |
| GET | `/account/stat/category` | 分类占比（`billType`/`beginDate`/`endDate`） |
| GET | `/account/stat/trend` | 近 N 月趋势（`months`，缺失月份补 0） |
| GET | `/account/stat/rank` | 排行（`billType`/`beginDate`/`endDate`/`limit`），返回分类排行与单笔排行 |
| GET | `/account/account/list` | 账户列表 + 实时余额 + 总资产/负债/净值 |
| POST | `/account/account` | 新增账户 |
| PUT | `/account/account` | 修改账户 |
| DELETE | `/account/account/{ids}` | 删除账户（有账单时拒绝） |
| GET | `/account/bill/{billId}` | 账单详情（编辑回显） |
| GET | `/account/budget` | 查询某月预算与执行进度（含各分类已用） |
| POST | `/account/budget` | 保存预算，金额 0 表示删除该条 |
| POST | `/account/upload` | 上传记账图片，返回 `/account/uploads/xxx` |
| POST | `/account/ai/parse` | 自然语言解析，body `{text}` |
| POST | `/account/ocr` | 图片识别，multipart `file` |
| GET | `/account/recurring/list` | 周期规则列表（顺带补记到期账单） |
| POST/PUT | `/account/recurring` | 新增 / 修改周期规则 |
| DELETE | `/account/recurring/{ids}` | 删除周期规则（历史账单保留） |
| POST | `/account/recurring/{id}/toggle` | 启用 / 暂停 |
| GET | `/account/ledger/list` | 我加入的账本 |
| POST | `/account/ledger` | 创建共享账本 |
| PUT | `/account/ledger` | 重命名（仅拥有者） |
| POST | `/account/ledger/join` | 邀请码加入，body `{inviteCode}` |
| GET | `/account/ledger/{id}/members` | 成员与邀请码 |
| POST | `/account/ledger/{id}/leave` | 退出账本 |

账单与统计类接口支持请求头 `X-Ledger-Id` 指定账本，缺省用当前用户的默认账本。

## 八、Nginx 路由

配置文件：`/www/server/nginx/conf/panel_proxy.conf`（8081 HTTPS 站点，已备份 `.bak-zbcx`）

```nginx
location ^~ /account/ {           # 前端静态资源
    root /www/wwwroot;
    index index.html;
    try_files $uri $uri/ /account/index.html;
}

location ^~ /account-api/ {       # 后端接口，剥掉前缀转发至 9100
    proxy_pass http://127.0.0.1:9100/;
}
```

## 九、已知事项

1. **`module_zgis_data` 占位模块**：原仓库 `config/get_redis.py` 引用了 `module_zgis_data.service.table_cache_service.TableCacheService`，但该模块未随仓库提供，已创建占位实现（记录日志后跳过），不影响记账功能。如需真实逻辑，替换 `module_zgis_data/service/table_cache_service.py` 即可。
2. **依赖版本调整**：仓库 `requirements-pg.txt` 中部分版本在镜像上不存在或要求 glibc ≥ 2.28（CentOS 7 仅有 2.17），已调整为：`pandas 2.3.2`、`Pillow 12.2.0`、`psycopg2` → `psycopg2-binary 2.9.10`。
3. **端口 8082**：曾用于独立站点，外网安全组未放行，现统一走 8081 的 `/account/` 子路径。
4. **验证码**：`sys_config.sys.account.captchaEnabled` 已置为 `false`，如需恢复改为 `true` 并重启后端。
5. **测试数据**：库中保留 7 条历史账单（餐饮/交通/购物/工资），均已挂到「现金」账户，可删除。
6. **构建注意**：`npm run build:h5` 在 3 GB 内存机器上约需 100~150 秒，**不要用短超时**中断，否则会留下空的 `dist/build/h5`。当前内存限制设为 `--max-old-space-size=1800`。
7. **部署注意**：不要用 `rsync --delete` 直连站点目录，构建失败时会清空站点；当前流程为先 `rm -rf assets static index.html` 再 `cp`，`uploads` 目录需保留。
8. **emoji 图标**：分类/账户图标存的是 emoji，iOS 与 Android 原生支持；无 emoji 字体的 Linux 环境会显示为空白色块。服务端出口已做英文图标名 → emoji 的归一化，历史数据无需迁移。
9. **OCR 依赖**：图片识别使用服务器本地 `tesseract 3.04`（`chi_sim+eng`）。中文小字识别率一般，金额与日期较准，商户名可能有个别错字，故识别结果只用于**预填**，仍需用户确认。
10. **AI 记账可选 LLM**：默认走规则引擎（零依赖、离线可用）。配置 `ACCOUNT_LLM_KEY` / `ACCOUNT_LLM_BASE` / `ACCOUNT_LLM_MODEL` 后优先调用大模型，失败自动降级。
11. **周期记账为懒执行**：用户打开明细或统计时补记到期账单，不依赖后台调度器；单次最多补 60 条，并用 `(recurring_id, bill_date)` 幂等去重。
